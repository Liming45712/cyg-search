# 畅易阁角色筛选

面向 **《新水浒 Q 传》** 的畅易阁角色筛选桌面工具。从畅易阁获取指定区服的在售、公示角色及详情，缓存在本地，再按价格、职业、属性和装备条件筛选，帮助你缩小选角范围。

本工具用于查看和筛选角色，详情内嵌畅易阁官方页面，也可通过「浏览器打开」前往官网。应用不实现账号登录、下单或交易功能，也不是官方客户端。

游戏数据、商标等权益归各自权利方所有。本地缓存可能过期，项目不保证数据实时性或完整性；价格、角色状态与交易规则均以官网为准，购买及交易请通过官方平台完成。

## 功能概览

- **区服选择**：按大区、小区两列联动选择，支持搜索区服及合服名称，记住上次选择。
- **本地组合筛选**：支持角色名称、价格区间、职业多选、在售 / 公示状态、角色属性最低值，以及至尊 / 神佑装备类型。
- **卡片 / 表格切换**：卡片每行显示 2–3 个角色；紧凑表格支持列标题排序和自适应列宽。两种视图均展示主要属性，表格中的 VIP 以职业旁的徽标突出显示。
- **排序与滚动加载**：角色、星灵和装备列表均先显示 50 条，滚动接近底部时继续追加 50 条，也可点击「加载更多」。筛选或排序变化后回到第一批，底部显示已加载数量。追加只读取本地缓存，不请求官网。
- **官网详情**：应用内直接打开畅易阁角色页面，支持重新加载、页面缩放和转到浏览器。
- **双角色对比**：在卡片或表格勾选两个角色，点击「开始对比」，左右同时打开官网详情；两侧独立滚动，缩放比例统一。选中项在追加加载、筛选和视图切换后保留，可移除或清空。
- **本地缓存**：获取过的数据可在重启后继续查看和筛选；支持暂停、失败重试和主动刷新详情。
- **星灵 / 灵宝计算器**：独立 Tab，按拙耳属性计算表的蓝色格子手动输入，实时显示星灵面板、五维和角色获得的 8 项加成；无需拉取角色数据。
- **星灵选购**：独立 Tab 获取当前区服的在售、公示星灵，支持表格 / 卡片、价格与品质筛选、五项资质和八项角色加成筛选及排序，支持官网详情与双星灵官网对比。

### 星灵选购

选择「星灵选购」Tab 后，使用顶部区服与「拉取 / 更新」获取星灵。可切换查看「角色加成」和「五项资质」，点击星灵名称查看当前面板与八项加成明细。已转星将开关统一控制列表和明细中的 1.1 倍系数。

计算直接使用官网当前面板乘以资质品质、成长品质及强化比例之和，不再重复叠加慧心、加点或灵宝效果，也不模拟升级或重新加点。缺少详情、未知品质或缺失数值时，加成显示为 `—`，不会当作零。更新时先匹配列表，仅获取新增、变化、缺失、失败或待刷新的详情；勾选「全量刷新详情」才会强制重取全部详情。

点击星灵表格、卡片或计算明细中的「模拟」，会跳转到计算器并带入所选详情中的等级、资质/成长品质、强化、慧心和五项资质；体力资质对应计算器的体质资质，转星将开关沿用选购页设置。支持保留 1、50、157 等实际等级，模拟计算范围为 0–159 的整数（0 表示不带星灵），不擅自改成 159 级。

领悟点数及官网缺失的慧心默认按 1 模拟（已有官网慧心值原样保留）、加点方向设为「无」、灵宝细项留空按 0 模拟，页面提示按方案补充；缺少或无法识别的已知字段也留空，不借用 Excel 示例。模拟用于重新设定等级/加点等方案，不保证复现官网现有面板。重复导入会重置上一件的模拟输入；恢复表中示例会清除导入来源；导入不会修改选购数据或重新请求官网。

星灵使用同一数据目录下独立的 `spirits.db` 缓存，暂停、重试、刷新和清理仅影响该区服的星灵，不修改 `cyg.db` 中的角色缓存。购买前请核对官网数据，Excel 折算规则尚未做游戏内实测校准。

### 装备选购

打开「装备选购」Tab，选区服后点击「拉取 / 更新」，获取官网当前在售及公示装备。默认先匹配列表，只更新新增、变化、缺失或失败的详情；勾选全量刷新时沿用风险提示。装备单独缓存在 `equipment.db`，不修改角色或星灵缓存。

按宠物、凤翼凰羽、黄金甲、召唤兽、常规装备及其他分组，类型支持跨组多选。属性面板固定高度，右侧独立滚动，最低值输入框位于上方，默认选中暴击率且最低值为空。基本攻击力、基本精神力和基本防御力分别归一为攻击力、精神力、防御力；原文仍保留在详情缓存。重复属性逐条匹配、不相加；宝石、星石、强化石、魂技及套装条件说明单独保留，不计入装备自身属性最低值。

卡片显示官方品质徽标、售价、公示/在售及剩余时间，支持价格和评分排序、名称/效果搜索、两件装备按属性对齐比较、官网详情、滚动加载更多。解析失败显示具体原因并保留旧详情，不以缺失数值冒充零。类型与属性选项以已核实的全区服上架商品为基础，也会显示本地商品中新发现的字段；尚未出现的历史类型或属性可能仍未覆盖。效果说明可通过关键词检索，不转成无依据的数值加成。搜索命中的名称、元信息、数值、效果及套装原文统一高亮命中词，重复命中全部标记，列表与对比一致；清空搜索后恢复原文显示。

### 游戏币

「游戏币」Tab（位于计算器前） 按所选区服获取在售及公示报价，官方币种名称为银两。表格显示数量（亿银两）、总价（元）、单价（万银两/元）、状态及截止时间，默认按单价降序排序，支持点击单价表头切换升降序并与顶部排序选项同步，无法计算的单价始终排在末尾，也支持按总价升序、价格范围、状态及名称筛选，并可打开官网详情。

换算严格识别名称中的数量单位：`1 亿 = 100,000,000 银两`，`1 元可买银两 = 数量（亿）×100,000,000÷售价（元）`。例如官网 `银两 x2.6亿`、96 元，对应每元约 `270.8333 万银两`（`2,708,333.33 银两`），不以官网四舍五入后的“元/万”倒算。无明确数量单位、缺少价格或零价格时不显示误导性比值。

游戏币报价已在列表中完整提供，更新不逐件拉取详情，也不显示全量刷新详情选项；缓存使用独立 `currency.db`。成交/下架清理、暂停及分页保护复用已有流程，不影响角色、星灵或装备缓存。追加加载和筛选均只读取本地数据。

### 星灵 / 灵宝计算器

打开「星灵 / 灵宝计算器」Tab，填写等级、资质品质、成长品质、强化星级、慧心、领悟点数、加点方向及灵宝属性。五项资质须填入包含灵宝影响后的最终数值。输入与角色筛选互不关联，切换 Tab 保留输入，重新打开应用恢复 Excel 示例。

公式沿用拙耳 Excel：品质比例与强化比例相加后折算星灵面板，已转星将再乘 1.1；神逆灵宝开关控制慧心固定点数。灵宝空值按 0 计算，必填数值缺失时提示补全。显示最多 6 位小数，中间不取整。选择「不带星灵」仅清零等级点数，慧心、领悟及灵宝属性仍按填写值计算。公式尚未通过游戏面板实测校准。

当前版本为 **0.7.0**。已配置 GitHub Actions 自动打包 macOS 通用版 `.app.zip`（Apple Silicon / Intel）和 Windows x64 绿色版 `.exe`；macOS 最低系统版本配置为 11.0。暂未配置 Linux 安装包。

## 开始使用

### 从源码启动

准备以下开发环境：

- Node.js 20.19 或更高版本及 npm。
- Rust 工具链与 Cargo。
- macOS 上的 Xcode Command Line Tools。
- Windows 上的 Microsoft C++ Build Tools（勾选「使用 C++ 的桌面开发」）、Rust MSVC 工具链及 Microsoft Edge WebView2。

```sh
git clone https://github.com/Liming45712/cyg-search.git
cd cyg-search
npm ci
npm run tauri -- dev
```

首次启动 Rust 后端时需要下载和编译依赖，请等待桌面窗口打开。

### 获取并筛选角色

1. 选择大区和小区。没有区服缓存时，内置回退选项为「电信一区 · 侠客岛」；区服表可从官网刷新。
2. 点击右上角「拉取 / 更新」。应用先获取该区服的在售、公示列表，再逐条获取需要补充的角色详情。
3. 在左侧设置价格、职业、装备和属性条件；名称搜索位于列表上方。筛选在本地执行，不会因每次修改条件而重新请求官网。
4. 点击角色名称或「详情」，在应用内查看官网页面。勾选两个角色后点击「开始对比」，左右查看官网详情；窄窗口可调整页面缩放。官网页面需要联网，与本地筛选缓存分别更新。
5. 有意向的角色可点击「在官网查看」，在畅易阁核对最新价格、状态和交易条件。

抓取过程中可点击「暂停」。暂停会等待当前请求结束，单次请求超时为 25 秒。再次拉取会重新检查列表，并继续获取缺失、失败或待刷新的详情，已成功获取的详情默认复用。

## 筛选规则

| 条件 | 匹配规则 |
| --- | --- |
| 名称 | 包含匹配，支持中文；英文字母不区分大小写 |
| 价格 | 支持最低价和最高价，包含边界；留空的一侧不限 |
| 职业 | 多选职业之间为「或」关系 |
| 商品状态 | 可选择在售、公示中，或不限 |
| 角色属性 | 每项只设置最低值，按「属性值 ≥ 输入值」匹配；多项属性须同时满足 |
| 装备 | 支持至尊 / 神佑的武器、项链、戒指、防具，可选择满足全部或任一已选类型 |

不同类别的筛选条件需要同时满足。价格下限高于上限时，界面会提示修正区间。

属性列表包含等级、装备总评分、铭石总等级、星石总等级及抗性等常用项。获取详情后，其他解析到数值的属性也可通过「其他属性」搜索并添加。

**缺失数据不会当作零。** 设置了某项属性最低值后，缺少该属性的角色会被排除；排序时缺失值始终排在最后。列表中的缺失值显示为 `—`，不代表角色实际属性为零。

装备条件只判断是否具有对应类型，**不按件数筛选**。例如，1 件和 5 件神佑防具都满足「神佑防具」条件。本地筛选使用的装备统计范围为详情页面的装备区域。

## 更新与缓存

### 列表更新和详情更新是两件事

每次点击「拉取 / 更新」都会重新检查所选区服、当前分类的商品列表，先按商品编号匹配缓存，再比对名称、标题、职业、价格、状态、上架 / 下架时间、列表属性和官网更新时间。列表内容相同且详情已成功缓存的商品跳过详情请求，只有新增、变化、缺失、失败或待刷新的详情进入更新队列。进度中会显示需更新和复用缓存的数量。

旧缓存没有列表属性或官网更新时间时，首轮先比对已有字段，并记录新字段作为后续比对基线，不因补齐新字段强制重刷全部详情。此后列表属性或官网更新时间变化才会触发详情更新。暂停、刷新失败后，待更新标记不会被下一轮相同列表清掉；成功获取详情后才清除。

若官网详情已变化，但列表字段和更新时间均未变化，列表匹配无法发现。需要核对这类变化时，勾选「全量刷新详情」后再拉取，强制重取当前区服、当前分类的全部详情。刷新过程中会保留旧详情；请求或解析失败时记录错误，成功后才替换旧数据。

勾选「全量刷新详情」会先弹出风险提示，说明访问量增加，以及频繁拉取可能触发平台监控、风控或限流。确认后才启用全量刷新；取消或关闭弹框保持未勾选，取消已勾选的选项不会再次弹框。弹框确认仅启用该选项，仍需点击「拉取 / 更新」才开始请求。

| 详情状态 | 含义 |
| --- | --- |
| 待获取 | 尚无成功获取的详情 |
| 已缓存 | 已有成功获取的详情，仍需注意获取时间 |
| 待刷新 | 已标记重新获取，但尚未完成 |
| 获取失败 / 更新失败 | 本次详情请求或解析失败；已有旧详情时继续保留 |

### 缓存位置

macOS 下的 SQLite 数据库位于：

```text
~/Library/Application Support/com.local.cygfinder/cyg.db
```

数据库保存角色列表、详情、更新时间、错误状态和区服表。上次选择的区服保存在 WebView 的本地存储中。

备份缓存前请先退出应用。数据库使用 WAL 模式，如目录中仍有 `cyg.db-wal`、`cyg.db-shm` 文件，请与数据库一起备份。

### 旧角色的清理规则

列表按页写入，每页使用独立事务。只有在售和公示列表均获取完成、未发现重复分页且数量校验通过后，才清理当前区服中不再出现在本轮列表里的角色，其他区服的缓存不受影响。

列表失败或在列表阶段暂停时，不清理旧角色。列表全部获取完成但出现重复分页、数量校验不通过或本轮完全为空时，仅对本轮列表中缺失的缓存商品逐个核查官网销售状态；商品编号、游戏、区服和分类均匹配，且明确显示已销售、已售出或已下架时才移除。核查失败、状态未知或仍在售的商品保留缓存，完成提示显示保留数量。这不会触发全部属性详情刷新。详情阶段暂停时，列表阶段可能已经完成清理。

## 本地开发与打包

技术栈：**Tauri 2 + Vue 3 + Element Plus + TypeScript + Rust + SQLite**。

| 命令 | 用途 |
| --- | --- |
| `npm ci` | 按锁文件安装前端依赖 |
| `npm run dev` | 启动浏览器界面预览，地址为 `http://127.0.0.1:1420` |
| `npm run tauri -- dev` | 启动带 Rust 后端的桌面开发模式 |
| `npm run build` | 检查前端类型并构建到 `dist/` |
| `npm run bundle:mac` | 构建当前 Mac 架构的调试版 `.app`，并执行本地 ad-hoc 签名 |
| `npm run bundle:windows` | 在 Windows 上构建当前架构的 release 版免安装 `.exe` |
| `npm run tauri -- build` | 构建 release 版桌面应用 |

**浏览器模式仅用于预览界面**，无法调用 Tauri 后端，不会获取或保存真实角色数据。完整功能请在桌面模式中使用。

macOS 产物路径为：

```text
# 调试构建
src-tauri/target/debug/bundle/macos/畅易阁角色筛选.app

# Release 构建
src-tauri/target/release/bundle/macos/畅易阁角色筛选.app
```

`bundle:mac` 的本地 ad-hoc 签名不等同于 Apple Developer ID 签名或公证。当前仓库没有配置正式分发签名流程。

### GitHub Actions 自动打包

工作流：[Build desktop apps](https://github.com/Liming45712/cyg-search/actions/workflows/build.yml)，配置位于 [`.github/workflows/build.yml`](.github/workflows/build.yml)。

- 推送到 `main`、推送 `v*` 标签或提交 Pull Request 时自动运行。
- 也可进入上述工作流，点击 **Run workflow** 手动打包。
- 每个平台先运行前端测试、类型检查和 Rust 本地测试，再生成 release 产物；实时官网抓取测试不在 CI 中执行。
- 运行成功后，在该次运行页面的 **Artifacts** 中下载，产物保留 30 天；下载需要登录 GitHub。此流程不自动创建 GitHub Release。

| Artifact | 内容 |
| --- | --- |
| `cyg-search-macos-universal` | 通用版 `.app.zip`，解压后得到 `.app`，兼容 Apple Silicon 和 Intel |
| `cyg-search-windows-x64` | Windows x64 绿色版 `.exe` 与使用说明，下载解压后直接运行 |

CI 使用 Node.js 22 和 Rust stable，通过 `npm ci` 与 Cargo 的 `--locked` 使用锁定依赖。macOS 在一个任务中构建 ARM64、x86_64 并合并为通用版，压缩前验证两种架构和 ad-hoc 签名。配置参考 [Tauri 的 GitHub Actions 指引](https://v2.tauri.app/distribute/pipelines/github/)。

无需配置签名 Secrets 即可运行。macOS 产物仅使用 ad-hoc 签名，未经过 Apple Developer ID 签名或公证；Windows 程序未配置代码签名，首次打开时系统可能显示安全或未知发布者提示。

### Windows 打包

在准备好上述开发环境的 Windows 电脑上执行：

```sh
npm ci
npm run bundle:windows
```

Tauri 会自动合并 `src-tauri/tauri.windows.conf.json`，使用 Windows `.ico` 图标，并跳过安装程序生成。可执行文件输出到 `src-tauri/target/release/cyg-finder.exe`，可重命名为「畅易阁角色筛选.exe」直接运行。CI 构建的 x64 文件位于 `src-tauri/target/x86_64-pc-windows-msvc/release/cyg-finder.exe`，与 [Windows 使用说明](docs/windows-portable.txt) 一起上传；CI 从最终产物目录启动程序并检查是否创建窗口。

绿色版使用系统已安装的 Microsoft Edge WebView2 Runtime，不附带完整浏览器运行时；缺少时需要先从微软官网安装。角色、星灵缓存和界面设置继续保存在系统用户数据目录，移动程序不影响已有缓存，也不会将这些缓存随程序一起迁移到其他电脑。

区服必须在本次启动中成功从官网获取，且所选区服属于官网返回列表，才能拉取角色或星灵数据；区服刷新失败会禁用拉取，默认区服和本地缓存仅用于查看已有数据。操作错误在右下角保留完整原因，支持复制和手动选择文字。

## 已知限制

- **一次只更新一个区服**，详情最多 5 个并发请求，结果逐条保存；暂停后停止派发新请求，并等待已发出的请求完成保存；不支持跨区并行抓取。
- **缓存不是实时数据**，尤其是默认复用的角色详情。购买前请在畅易阁核对。
- **依赖第三方接口和页面结构**，官网接口调整、维护或详情 HTML 变化可能导致获取或解析失败。
- **当前数据请求使用 HTTP**，涉及 `cyg.changyou.com` 和 `public.npt.changyou.com`。HTTP 不提供传输加密或完整性保护，网络链路可能影响返回内容；应用不提交账号、密码或交易信息。
- 暂未实现收藏、通知、价格历史和图片缓存。
