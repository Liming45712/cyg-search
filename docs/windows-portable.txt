畅易阁角色筛选 — Windows x64 绿色版

将下载的压缩包完整解压到可写的文件夹，双击“畅易阁角色筛选.exe”运行，无需安装本程序。

系统要求：Windows 10 / 11 x64，并已安装 Microsoft Edge WebView2 Runtime。
本包使用系统 WebView2，不附带浏览器运行时。缺少运行时可从微软官网安装：
https://developer.microsoft.com/microsoft-edge/webview2/

角色、星灵缓存和界面设置保存在系统用户数据目录；移动或删除程序文件不会清除这些数据。
查询和更新官网数据需要联网。销售状态仅在“拉取 / 更新”后同步，交易时请核对官网。

本程序未做 Windows 代码签名；系统可能显示未知发布者提示。
